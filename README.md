# Thiên Di Education | French Grammar Lab A1–B2

A static web app for French grammar revision and TCF Canada practice.

## Features
- A1–B2 grammar roadmap with search and level filters
- Short lesson summaries and examples
- Interactive multiple-choice practice with explanations
- TCF Canada speaking and writing practice prompts
- B2 learning checklist
- Progress saved locally in the browser

## Run locally
Open `index.html` in a modern browser.

## Deploy to Vercel
Import this repository into Vercel. Framework preset: **Other**. Build command: leave empty. Output directory: `.`.
